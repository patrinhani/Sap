Manual de Uso - SAP Automação

Guia rápido para operar o aplicativo, retomar execuções interrompidas e gerar o executável.

Visão Geral

O aplicativo automatiza rotinas SAP de folha/documentos a partir de uma lista de matrículas, período e pasta de saída. A interface foi feita em PyQt6 e pode ser executada por python main.py ou empacotada como .exe.

O sistema usa senha informada no início da execução para abrir ou reconectar no SAP. A senha fica apenas em memória durante a execução e não é salva no arquivo de configuração.

Requisitos

SAP

  • SAP GUI instalado na máquina.
  • SAP GUI Scripting habilitado.
  • Conexão cadastrada no SAP Logon como 15. VIA ECP PRD Viavarejo.
  • Usuário do Windows compatível com o login SAP.

Python

  • Ambiente virtual .venv configurado no projeto.
  • Dependências instaladas: PyQt6, pywin32, pandas/openpyxl e PyInstaller.
  • Para gerar EXE, usar os scripts de build da pasta do projeto.

Primeiro Uso

  1. Abra o terminal na pasta do projeto: C:\Users\2160048370\Downloads\Automações\Sap.
  2. Execute python main.py ou abra o SapAutomacao.exe.
  3. Na aba Execução, selecione a pasta de saída.
  4. Informe a senha SAP.
  5. Escolha o período inicial e final.
  6. Cole ou digite as matrículas, uma por linha.
  7. Clique na rotina desejada.

Como Executar

Aba Execução

É a tela principal. Nela ficam pasta de saída, senha SAP, período, tipo de ficha financeira, lista de matrículas e botões das rotinas.

Antes de iniciar, o aplicativo valida se existe pasta de saída e se existe ao menos uma matrícula. A senha SAP é obrigatória porque pode ser necessária para reconexão automática.

Aba Progresso

Mostra o status geral, barra de progresso, itens processados e log em tempo real. É a melhor tela para acompanhar uma execução longa.

Aba Retomada

Mostra se existe checkpoint pendente. Quando houver uma execução interrompida, o botão lateral Retomada ! fica destacado em vermelho.

Retomada e Checkpoint

O checkpoint existe apenas enquanto a execução está incompleta. Quando a execução termina com sucesso, o checkpoint é apagado automaticamente.

Onde o checkpoint fica salvo

O aplicativo salva o checkpoint em dois lugares:

%APPDATA%\SapAutomacao\.sap_automacao_checkpoint.json
<pasta de saída>\.sap_automacao_checkpoint.json

A cópia global em %APPDATA% evita que a retomada desapareça quando a pessoa troca a pasta de saída na interface.

Como a retomada funciona

  • Se o SAP cair, o app espera 60 segundos e tenta novamente.
  • São feitas até 4 tentativas por etapa.
  • Na tentativa seguinte, o app reabre/reconecta no SAP e refaz o login com a senha informada.
  • Se a execução for fechada ou falhar de vez, o checkpoint fica salvo para retomada futura.
  • A aba Retomada usa os parâmetros do checkpoint, não os campos atuais da tela.

Exemplos de retomada

SituaçãoRetomada
Caiu depois de concluir HP Holerite Retoma no ZDP1 Holerite ou próxima etapa pendente.
Caiu no mês 2 de 12 Pula o mês 1 concluído e retoma no mês 2.
Caiu na matrícula 5 de 10 em processo individual Pula as matrículas 1 a 4 e retoma na matrícula 5.
Caiu dentro de lote mensal que processa várias matrículas juntas Retoma no mês/lote atual, porque a rotina SAP não expõe matrícula interna com segurança.

Arquivos Gerados

Os arquivos finais são salvos dentro da pasta de saída escolhida. A estrutura interna depende da rotina executada, por exemplo HP, HQ, ZDP1, ZDP2, CTPS ou Ficha Financeira.

Ao terminar com sucesso, o app limpa o checkpoint. Se a aba Retomada continuar mostrando checkpoint depois de uma execução concluída, recarregue a aba e confira se existe arquivo antigo em %APPDATA%\SapAutomacao.

Geração do EXE

Arquivo único

Use quando precisar distribuir um único arquivo:

cd /d "C:\Users\2160048370\Downloads\Automações\Sap"
build_exe.bat

Resultado:

dist\SapAutomacao.exe

Pasta rápida

Use quando a prioridade for abrir mais rápido:

cd /d "C:\Users\2160048370\Downloads\Automações\Sap"
build_exe_pasta_rapido.bat

Resultado:

dist\SapAutomacao\SapAutomacao.exe

Neste modo, mantenha a pasta dist\SapAutomacao inteira. Não copie apenas o executável.

Problemas Comuns

ProblemaO que verificar
EXE demora para abrir Use o modo pasta rápida. O modo arquivo único precisa extrair dependências antes de abrir.
Erro de conexão SAP Confirme o nome da conexão SAP, SAP GUI aberto/instalado e scripting habilitado.
Retomada não aparece Verifique se existe checkpoint em %APPDATA%\SapAutomacao ou na pasta de saída.
Senha pedida novamente É esperado. A senha não é salva no config por segurança.
Popup de segurança SAP O app tenta identificar e liberar automaticamente, mas a permissão do SAP GUI precisa permitir scripting.
