Guia da Interface

SAP Automação - instruções rápidas para operar o aplicativo.

Use este guia para saber onde clicar, o que preencher e como acompanhar uma execução.

Antes de Começar

  • Confirme se o SAP GUI está instalado no computador.
  • Tenha a senha SAP em mãos.
  • Tenha a lista de matrículas pronta.
  • Escolha uma pasta onde os arquivos serão salvos.

Telas do Aplicativo

Execução

Tela principal. Aqui você escolhe pasta de saída, senha, período, matrículas e rotina.

Progresso

Mostra o andamento da automação, itens processados e mensagens do log.

Retomada

Aparece quando existe uma execução interrompida que pode continuar.

Ajustes

Preferências simples, como salvar pasta selecionada e abrir este guia.

Como Executar uma Rotina

1

Selecione a pasta de saída

Na aba Execução, clique em Selecionar e escolha onde os arquivos serão gerados.

2

Informe a senha SAP

Digite a senha no campo Senha SAP. Ela é usada para abrir o SAP e reconectar caso a sessão caia.

3

Escolha o período

Informe mês e ano de início e fim. Exemplo: de 01/2025 até 12/2025.

4

Informe as matrículas

Cole as matrículas no campo de texto. Pode ser uma por linha. Use o botão de normalizar quando quiser organizar a lista.

5

Clique na rotina desejada

Escolha uma rotina no grupo desejado: Holerites, Anuais ou Documentos.

Como Acompanhar

Depois de iniciar, o aplicativo muda para a aba Progresso.

  • Status mostra a etapa atual.
  • Barra mostra o avanço geral.
  • Itens mostra o que está executando, concluído ou com erro.
  • Log mostra mensagens detalhadas.

Retomada

Se o aplicativo cair ou o SAP desconectar, pode aparecer a aba Retomada em destaque vermelho.

  • Clique em Retomada para ver onde parou.
  • Clique em Retomar agora para continuar.
  • A retomada usa os dados salvos da execução interrompida.
  • Se não quiser continuar, use Descartar checkpoint.

Quando Terminar

Quando a execução termina com sucesso, o aplicativo mostra uma mensagem de conclusão e limpa automaticamente a retomada pendente.

Dicas Rápidas

  • Se a senha estiver vazia, o aplicativo vai pedir antes de iniciar.
  • Se a pasta de saída estiver errada, clique em Selecionar novamente.
  • Se o SAP pedir permissão de segurança, aguarde: o aplicativo tenta liberar automaticamente.
  • Para consultar arquivos gerados, use o botão Abrir ao lado da pasta de saída.
